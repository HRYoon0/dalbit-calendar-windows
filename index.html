일정

구글 캘린더 그대로

로그인하면 내 캘린더와 공유받은 캘린더의 일정이 한 달 달력에 뜹니다. 며칠 이어지는 일정은 이어진 막대로 보여요.

대한민국 공휴일

로그인하지 않아도 공휴일과 대체공휴일이 빨간 날로 표시됩니다.

날짜를 눌러 추가

날짜를 누르면 그 주 아래로 그날 일정이 펼쳐집니다. 구글 캘린더에 넣을지, 이 PC에만 둘지 고를 수 있어요.

메모

달력 위에 붙은 메모 탭

탭을 누르면 포스트잇처럼 펼쳐지고, 다시 누르면 접힙니다. 이름과 색을 붙여 여러 장을 둘 수 있어요.

손글씨부터 명조까지

나눔손글씨, 주아, 감자꽃 같은 구글 폰트 20종 가운데 메모마다 글꼴과 크기를 고릅니다.

다른 PC에서도 이어서

구글에 연결하면 메모가 드라이브의 앱 전용 폴더에도 저장돼, 교실 PC와 집 PC에서 같은 메모를 봅니다.

화면

테마 12가지

다크, 미드나잇, 라떼, 포레스트, 민트 등 아이폰판 달빛 캘린더와 같은 색입니다. 위 미리보기에서 바로 바꿔 볼 수 있어요.

배경 투명도

바탕화면이 비쳐 보이도록 배경만 옅게 만들 수 있습니다. 글자는 또렷하게 남아요.

부드러운 달 넘김

마우스 휠이나 화살표로 달을 넘기면 일정이 새 자리로 날아가 앉습니다. 위 미리보기의 화살표를 눌러 보세요.

시작하는 방법

설치 과정 없이 압축만 풀면 됩니다.

  1. zip을 내려받아 압축을 풉니다원하는 폴더에 풀어 두세요. 그 안의 DalbitCalendar.exe가 앱 전부입니다.
  2. DalbitCalendar.exe를 실행합니다처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보]를 누른 뒤 [실행]을 누르세요.
  3. 오른쪽 위 [Google 캘린더 연결]을 누릅니다브라우저에서 계정을 고르고 허용하면 일정이 달력에 채워집니다. 다음부터는 자동으로 연결돼요.
  4. 설정에서 Windows 시작 시 실행을 켭니다톱니바퀴 버튼에서 켜 두면 컴퓨터를 켤 때마다 달력이 함께 열립니다.

내 일정과 메모는 어디로 가나요

  • 개발자의 서버는 없습니다. 일정은 내 PC와 구글 사이에서만 오갑니다.
  • 구글 캘린더 권한은 일정을 달력에 보여 주고, 내가 직접 누른 일정 추가와 삭제를 할 때만 씁니다.
  • 메모는 이 PC에 저장되고, 구글에 연결하면 내 드라이브의 앱 전용 숨김 폴더에도 저장됩니다. 드라이브의 다른 파일은 앱이 볼 수 없습니다.
  • 로그아웃하거나 구글 계정의 서드파티 액세스에서 언제든 권한을 거둘 수 있습니다.

Dalbit Calendar is a free Windows desktop calendar. After the user signs in with Google, it shows the user's Google Calendar events in a month view, lets the user add or delete events, and keeps memo tabs that sync through the app's hidden Drive application data folder so they appear on any PC. Google data is used only for these features and is exchanged only between the user's PC and Google. See the Privacy Policy and Terms of Service.
