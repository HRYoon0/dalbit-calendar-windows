달빛 캘린더 for Windows

Google 캘린더 일정을 PC 화면 가득 한 달 달력으로 보여 주는 Windows 앱입니다. 아이폰 위젯 앱 「달빛 캘린더」와 같은 화면 구성과 12가지 테마를 씁니다.

주요 기능

· Google 계정으로 로그인해 내 캘린더 일정을 한 달 달력에 표시
· 날짜를 눌러 그날 일정 확인, 두 번 눌러 일정 추가, 일정 삭제
· 여러 날 일정은 이어진 막대로 표시
· 테마 12가지, 배경 투명도, 화면 꽉 채우기

Google 사용자 데이터

이 앱은 Google 캘린더 일정을 화면에 보여 주고, 사용자가 요청한 일정 추가·삭제를 하기 위해서만 Google 캘린더 권한을 사용합니다. 일정은 사용자의 PC와 Google 사이에서만 오가며, 개발자의 서버로 전송되지 않습니다. 자세한 내용은 개인정보 처리방침을 확인해 주세요.

About (English)

Dalbit Calendar is a free Windows desktop calendar. After the user signs in with Google, it shows the user's Google Calendar events in a month view, lets the user add or delete events, and keeps memo tabs that sync through the app's hidden Drive folder so they appear on any PC. Google data is used only for these features and is exchanged only between the user's PC and Google. See the Privacy Policy and Terms of Service.
