개인정보 처리방침

최종 수정일: 2026년 10월 6일 (메모 드라이브 동기화 추가)

요약

달빛 캘린더 for Windows(이하 "앱")는 개발자의 서버로 어떤 개인정보도 수집·전송하지 않습니다. 앱은 사용자의 PC에서만 동작하며, Google 캘린더 데이터는 사용자의 PC와 Google 사이에서만 주고받습니다.

접근하는 Google 사용자 데이터

  • Google 캘린더 일정 (https://www.googleapis.com/auth/calendar.events): 사용자가 Google 캘린더에서 표시하도록 선택한 캘린더의 일정(제목, 시작·종료 시각, 색상, 일정 링크)을 읽고, 사용자가 앱에서 요청한 일정 추가·삭제를 수행합니다.
  • Google 캘린더 목록 (https://www.googleapis.com/auth/calendar.calendarlist.readonly): 표시할 캘린더 목록과 캘린더 색상, 일정을 추가할 수 있는 캘린더인지를 확인합니다.
  • 사용자가 앱에서 일정을 추가하거나 삭제하면 그 요청에 한해 Google 캘린더에 기록합니다.
  • Google 드라이브 앱 데이터 (https://www.googleapis.com/auth/drive.appdata): 메모 탭의 내용을 사용자 Google 드라이브의 이 앱 전용 숨김 폴더(appDataFolder)에 memos.json 한 파일로 저장해, 다른 PC에서 같은 계정으로 로그인해도 메모를 이어 쓸 수 있게 합니다. 이 권한으로는 사용자의 다른 드라이브 파일을 보거나 바꿀 수 없습니다.
  • 기본 프로필 (https://www.googleapis.com/auth/userinfo.profile): 이름과 프로필 사진을 읽어 앱 오른쪽 위 계정 버튼에 표시합니다.
  • 로그인한 계정을 계정 메뉴에 표시하기 위해 기본 캘린더의 식별자(이메일 주소)를 읽습니다.

데이터 사용 목적

  • 읽은 일정과 프로필은 앱 화면에 표시하는 용도로만 사용합니다.
  • 광고, 분석, 프로필 작성, 인공지능 학습 등 다른 목적으로 사용하지 않습니다.

저장과 보관

  • 로그인 정보(OAuth 토큰)와 앱 설정(테마, 창 위치 등)은 사용자 PC의 %AppData%\DalbitCalendar 폴더에만 저장됩니다.
  • 일정 데이터와 프로필 사진은 화면 표시를 위해 실행 중 메모리에만 두며, 앱을 종료하면 사라집니다.
  • 사용자가 "이 PC에만 저장"을 골라 추가한 일정은 사용자 PC의 %AppData%\DalbitCalendar\local.json에만 저장되며, Google이나 다른 곳으로 전송되지 않습니다.
  • 달력 위 메모 탭에 적은 내용은 사용자 PC의 %AppData%\DalbitCalendar\memos.json에 저장됩니다. Google 계정에 연결한 경우에만 위의 드라이브 앱 전용 폴더에도 저장되며, 그 밖의 곳으로는 전송되지 않습니다.
  • 한 PC에서 다른 Google 계정으로 로그인하면, 앞 계정의 메모가 새 계정 드라이브에 섞이지 않도록 이 PC의 메모를 같은 폴더에 백업 파일로 옮겨 두고 새 계정의 메모를 불러옵니다.

공유와 전송

  • 앱은 Google API 외의 곳으로 데이터를 전송하지 않습니다. 개발자 서버, 분석 도구, 광고가 없습니다.
  • 메모 글꼴로 구글 폰트를 처음 고르면, 그 글꼴 파일을 Google Fonts 공식 저장소(GitHub, raw.githubusercontent.com/google/fonts)에서 내려받아 %AppData%\DalbitCalendar\fonts에 저장합니다. 이때 사용자 데이터는 보내지 않습니다.
  • Google 사용자 데이터를 제3자에게 판매하거나 제공하지 않습니다.

Google API 서비스 사용자 데이터 정책 준수

달빛 캘린더 for Windows가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

삭제와 권한 철회

  • 앱 오른쪽 위 계정 버튼을 눌러 로그아웃하면 PC에 저장된 로그인 정보가 삭제됩니다.
  • Google 계정 > 서드파티 액세스에서 언제든 앱의 권한을 철회할 수 있습니다.
  • %AppData%\DalbitCalendar 폴더를 지우면 앱이 이 PC에 저장한 모든 정보가 삭제됩니다.
  • 드라이브에 저장된 메모는 Google 드라이브 웹의 설정 > 앱 관리 > 달빛 캘린더 > 숨겨진 앱 데이터 삭제로 지울 수 있습니다.

Privacy Policy (English summary)

Dalbit Calendar for Windows ("the app") runs entirely on the user's PC. The developer operates no server and collects no personal data.

Google user data the app accesses

  • calendar.events: reads events from the calendars the user chose to show in Google Calendar, to display them in the month view, and creates or deletes an event only when the user explicitly asks in the app.
  • calendar.calendarlist.readonly: reads the list of calendars, their colors, and whether the user can add events to them.
  • drive.appdata: stores the user's memo tabs as a single file (memos.json) in the app's hidden application data folder in the user's Google Drive, so the same memos appear when the user signs in on another PC. The app cannot see or change any other Drive files.
  • userinfo.profile: reads the user's name and profile picture to show the signed-in account in the app.

Use, storage and sharing

  • Data is used only to show it in the app's user interface and to perform actions the user requests. It is not used for advertising, analytics, profiling, or AI training.
  • The OAuth token and settings are stored only in %AppData%\DalbitCalendar on the user's PC. Calendar data is kept in memory while the app runs.
  • Data is exchanged only between the user's PC and Google APIs. It is never sold or transferred to third parties.
  • When the user first picks a Google Font for a memo, the app downloads that font file from the official Google Fonts repository on GitHub (raw.githubusercontent.com/google/fonts) and stores it in %AppData%\DalbitCalendar\fonts. No user data is sent in this request.

Limited Use

Dalbit Calendar for Windows's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion

  • Signing out in the app deletes the stored token from the PC. Access can be revoked at any time at myaccount.google.com/permissions.
  • Memos stored in Drive can be removed in Google Drive > Settings > Manage apps > Dalbit Calendar > Delete hidden app data.
